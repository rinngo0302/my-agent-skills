# ドキュメント作成

## 概要

コードや機能のドキュメントを作成する際のスキルです。
README や API ドキュメント、設計書を書く際に使用します。

## プロンプト

```
以下のコード・機能についてドキュメントを作成してください。

含める内容:
1. **概要**: 何をするものか1〜2文で説明
2. **使用方法**: インストール手順や基本的な使い方
3. **パラメータ/オプション**: 設定できる項目の一覧と説明
4. **使用例**: 実際のコード例
5. **注意事項**: 既知の制限や注意点（あれば）

マークダウン形式で記述し、日本語で作成してください。
```

## 使用例

**入力例:**

```javascript
function debounce(fn, delay) {
  let timer;
  return function(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}
```

**出力例:**

```markdown
## debounce

### 概要
関数の呼び出しを指定した遅延時間だけ遅らせ、連続して呼び出された場合は最後の呼び出しのみを実行します。

### 使用方法
...
```

## メモ

- 読者のレベルに合わせて説明の詳細度を調整する
- コード例は実際に動くものを使用する
