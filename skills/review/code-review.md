# コードレビュー

## 概要

プルリクエストやコードの変更をレビューする際に使用するスキルです。
品質・セキュリティ・可読性の観点から指摘事項をまとめます。

## プロンプト

```
以下のコードをレビューしてください。次の観点でフィードバックをお願いします。

1. **バグ・ロジックエラー**: 動作上の問題がないか
2. **セキュリティ**: 脆弱性や危険な処理がないか
3. **可読性**: 変数名・関数名・コメントが適切か
4. **パフォーマンス**: 不必要な処理や改善できる箇所がないか
5. **テスト**: テストカバレッジや境界値の考慮が十分か

問題がある場合は、該当箇所と改善案を具体的に示してください。
問題がない場合は「問題なし」と答えてください。
```

## 使用例

**入力例:**

```python
def get_user(user_id):
    query = "SELECT * FROM users WHERE id = " + user_id
    return db.execute(query)
```

**出力例:**

```
## レビュー結果

### セキュリティ
- **SQLインジェクションの脆弱性**: `user_id` を文字列結合でクエリに埋め込んでいます。
  プレースホルダを使用してください。

  改善案:
  ```python
  def get_user(user_id):
      query = "SELECT * FROM users WHERE id = ?"
      return db.execute(query, (user_id,))
  ```
```

## メモ

- セキュリティの指摘を最優先で行う
- 指摘は具体的なコード例を添えると効果的
